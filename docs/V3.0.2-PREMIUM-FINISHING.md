## Changes made

| Area | Demonstrated issue | Targeted refinement |
| --- | --- | --- |
| San Diego fair card | At 320px, the intended `San Diego` / `County` heading wrapped to three lines because the available card text width was 218px while the first line measured about 223px. | A 320–360px-only `3.15rem` font size on this heading preserves the intended two lines without clipping, transforms, or changing card dimensions. |
| Fair navigation | Fair-related pages had no active treatment in the primary navigation because the current item is a dropdown parent rather than a direct route link. | The existing Fairs button receives the same understated active treatment as direct current-page links when one of its four existing routes is active. |
| Reveals and interaction feedback | The baseline reveal moved 24px over 700ms and the V6.1 card/button transitions were broad, without a fine-pointer-only interaction boundary. | Reveal motion is now a short 16px / 460ms opacity-and-translate transition. Card/button transitions name only their visual properties. Fine-pointer cards lift 5px; coarse pointers retain no hover lift and receive only a small active button response. |

No routes, copy, branding, fair information, analytics configuration, image source, domain, DNS, Cloudflare, Wix, or site architecture changed.
